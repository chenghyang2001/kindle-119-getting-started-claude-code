# 全域 CLAUDE.md 範本（~/.claude/CLAUDE.md）

> 這只是範本，示範「個人層級」該放什麼。本練習**不會**修改真正的 `~/.claude/CLAUDE.md`。
> 原則：全域只放「跨所有專案都成立的個人偏好」；技術堆疊、資料夾結構等放專案 CLAUDE.md。

## 溝通

- 一律用繁體中文回覆；程式碼註解也用繁體中文
- 回答先講結論，再補細節

## 程式風格偏好

- TypeScript 一律 `strict`；不使用 `any`
- 偏好小函式（≤ 30 行）、早 return，避免深層巢狀
- 變數命名描述內容，布林值以 `is`／`has`／`can` 開頭

## 工作流程

- 修改前先讀相關檔案，不憑猜測改 API
- 完成後跑測試與建置，回報結果；失敗要附錯誤訊息
- commit message 用繁體中文，格式「動詞 + 簡短說明」
- 未經同意不 push、不 force push

## 安全

- 不把 API key／token 寫進程式碼，一律讀環境變數
- 不執行 `rm -rf`、`git reset --hard` 等破壞性指令，除非明確要求
